ip2region 离线公网 IP 地理库
============================

文件名（当前官方）：ip2region_v4.xdb
放置路径：与本文件同目录 assets/ip2region_v4.xdb

说明：旧版 ip2region.xdb 已从官方仓库移除（链接 404），请使用 v4 文件。

获取方式（任选其一）：
  1. 在项目根目录运行：python scripts/download_ip2region.py
  2. 打包前 build.bat 会自动尝试下载
  3. 浏览器打开并下载：
     https://github.com/lionsoul2014/ip2region/blob/master/data/ip2region_v4.xdb
     点击 Raw / Download，保存为本目录下的 ip2region_v4.xdb

内网 / 隔离环境有没有副作用？
  - 运行时：纯本地查表，不访问外网，不发起任何 GeoIP API
  - 内网 IP（10/172/192 等）不会查库，仍走「内网 inset」或手动 geo
  - 磁盘约 10MB；启动后若存在 xdb 会占用相近量级内存
  - 坐标为城市级近似值，仅供态势地图展示，不影响监测逻辑
  - 删除此文件即可关闭公网自动定位，不影响 ping/告警/拓扑

没有此文件时：请在 config 里为目标配置 geo.lat / geo.lon，或接受公网目标暂不自动打点。
